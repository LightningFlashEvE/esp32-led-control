ESP32 LED控制电路连接图

组件清单:
- ESP32 DEVKIT_C 开发板 x1
- LED灯 x1
- 220Ω电阻 x1
- 面包板
- 跳线若干

电路连接:
┌─────────────────────────────────────────────────────────────────┐
│                        ESP32 DEVKIT_C                          │
│                                                                 │
│  ┌─────┐                                                       │
│  │ GND │────────────────────────────────────────────────┐      │
│  └─────┘                                                │      │
│                                                         │      │
│  ┌─────┐     ┌─────────┐     ┌─────┐     ┌─────────┐   │      │
│  │ D2  │─────│  220Ω   │─────│ LED │─────│   GND   │───┘      │
│  │GPIO2│     │  电阻   │     │ +   │     │   -     │          │
│  └─────┘     └─────────┘     └─────┘     └─────────┘          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

连接说明:
1. ESP32的GPIO2引脚连接到220Ω电阻的一端
2. 220Ω电阻的另一端连接到LED的正极(长脚)
3. LED的负极(短脚)连接到ESP32的GND引脚

注意事项:
- 必须使用限流电阻，防止LED烧毁
- 注意LED的极性，正极连电阻，负极连GND
- 确保连接牢固，避免接触不良
